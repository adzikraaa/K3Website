# K3 Website — PT Nusantara Apparel Industri 🏭

> Website profil Keselamatan dan Kesehatan Kerja (K3) untuk PT Nusantara Apparel Industri, mencakup informasi APD, HIRADC, prosedur darurat, dan standar keselamatan kerja di industri garmen.

---

## 🌐 Tentang Website

Website ini dikembangkan sebagai Project Based Learning (PBL) Kelompok 4, Politeknik Negeri Malang, sebagai media informasi dan edukasi K3 bagi karyawan dan manajemen PT Nusantara Apparel Industri. Website dirancang dengan tampilan modern, profesional, dan informatif.

---

## ✨ Fitur & Konten

| Halaman / Seksi | Deskripsi |
|---|---|
| 🏠 **Hero Section** | Profil singkat perusahaan dan visi K3 |
| 🦺 **APD (Alat Pelindung Diri)** | Informasi 5 jenis APD wajib industri garmen dengan animasi interaktif |
| ⚠️ **HIRADC** | Identifikasi bahaya dan penilaian risiko kerja |
| 🚨 **Prosedur Darurat** | Panduan tanggap darurat dan evakuasi |
| 📋 **SMK3** | Sistem Manajemen Keselamatan dan Kesehatan Kerja |
| 👥 **Tim K3** | Profil anggota tim pengembang |

---

## 🎨 Desain

- **Tema**: Navy Blue modern dengan gradient gelap
- **Font**: Syne + Plus Jakarta Sans (Google Fonts)
- **Efek**: Animated cards, scroll reveal, glassmorphism
- **Responsif**: Mobile, tablet, dan desktop

---

## 🛠️ Tech Stack

- **HTML5** — Struktur semantik
- **CSS3** — Styling & animasi (Vanilla CSS, tanpa framework)
- **JavaScript** — Interaktivitas & efek dinamis

## 🚀 Cara Membuka

Tidak memerlukan instalasi apapun — cukup buka langsung di browser:

```bash
# Clone repository
git clone https://github.com/adzikraaa/K3Website.git

# Buka file utama
cd K3Website
# Double-click index.html atau drag ke browser
```

> **Catatan**: Murni static website, tidak memerlukan server atau backend.
